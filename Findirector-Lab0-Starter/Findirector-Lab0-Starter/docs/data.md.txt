# Описание данных (ЛР2-Д5)

Система сохраняет только исходные планы. Отчёты (результаты) не сохраняются, а вычисляются на лету при загрузке плана.

## Сущность: План (Plan)
* **Id (GUID):** Уникальный идентификатор плана.
* **Name (String):** Название плана (например, "Оптимистичный").
* **Months (Список):** Список из трёх объектов `MonthPlan`.

## Сущность: Параметры месяца (MonthPlan)
* **PlanId (GUID):** Ссылка на родительский план (внешний ключ).
* **MonthNumber (Int):** Номер месяца (1, 2 или 3).
* **Quantity (Int):** Количество услуг.
* **Price (Decimal):** Цена услуги.
* **UnitCost (Decimal):** Переменные затраты на услугу.
* **FixedCosts (Decimal):** Постоянные расходы за месяц.
* **PaidNowPercent (Int):** Процент оплаты в текущем месяце.

*Связь:* Один План содержит ровно три Месяца (связь 1 ко многим, ограниченная тремя).
